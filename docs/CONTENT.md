### 4. Technical Challenges & Engineering Solutions

#### Challenge 1: JS Thread Congestion during High-Frequency Polling
* **Problem:** Ingesting live telemetry payloads every 10 seconds caused visual jank and input delay when processed through standard React component state re-renders.
* **Solution:** Decoupled telemetry state updates from UI animation rendering. Telemetry updates update normalized RTK Query cache slices, while particle animation loops execute entirely on the native UI thread using React Native Reanimated (v3) shared values.

#### Challenge 2: Custom Interactive Graphing without WebViews
* **Problem:** Rendering complex time-series solar generation and battery charge curves using heavy WebViews or unoptimized libraries degraded frame rates on lower-spec Android devices.
* **Solution:** Built custom SVG charting components combining D3.js scale generators (`d3-scale`, `d3-shape`) mapped directly to React Native SVG `<Path>` primitives. Integrated touch gestures via React Native Gesture Handler to allow instant point inspection without re-rendering the underlying graph tree.

#### Challenge 3: Battery Conservation & Background Lifecycles
* **Problem:** Continuous HTTP polling and active animation loops running while the application was backgrounded led to battery drain and App Store submission flags.
* **Solution:** Bound application state transitions to the React Native `AppState` API (`active` -> `background`). Upon backgrounding, RTK Query polling timers are suspended and Reanimated animation loops are frozen, ensuring zero CPU overhead when the app is out of focus.

#### Challenge 4: Multi-Environment Build & Code-Signing Automation (Fastlane DevOps)
* **Problem:** Managing separate white-label target bundles (`com.duracell` vs `com.puredrive.app`), expiring iOS distribution certificates, and manual Xcode exports caused release friction.
* **Solution:** Integrated Fastlane automation into the application repository. Configured `Fastfile` lanes (`lane :beta_ios`, `lane :beta_android`) utilizing Fastlane Match with encrypted Git certificate storage and build flavor injection via `react-native-config`.
